## Tech

A single static page, no build step:

- Hand-written **HTML, CSS and vanilla JavaScript**
- Animations with **GSAP**, **AOS** and **Lottie**
- **qrcode.js** for the share QR code
- Open Graph tags for clean link previews, lazy-loaded screenshots

## Run locally

```bash
git clone https://github.com/NourMontacer01/personal-portfolio.git
cd personal-portfolio
# any static server works, for example:
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Deploy

The site is served by **GitHub Pages** from the `main` branch: pushing to `main` updates it.
